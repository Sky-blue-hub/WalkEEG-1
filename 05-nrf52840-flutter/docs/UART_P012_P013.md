# 用 P0.12 / P0.13 做 NUS ↔ USB 串口

固件已把 `uart0`（NUS 桥）改到：

| 方向 | 引脚 |
|------|------|
| TX（板子发出） | **P0.13** |
| RX（板子接收） | **P0.12** |
| 波特率 | **115200 8N1** |

P0.06 / P0.08 **未改动**，留给主板。

## 接线（USB-TTL，必须交叉）

| USB-TTL 模块 | nRF52840 |
|--------------|----------|
| RX | **P0.13** |
| TX | **P0.12** |
| GND | **GND** |
| 不接 | 5V（除非确认需要供电） |

PuTTY / 串口助手连的是 **USB-TTL 的 COM 口**，不是 J-Link COM6。

## 手机蓝牙验证步骤

1. 接好 USB-TTL，打开串口工具：115200，无流控
2. RESET 板子，约每 3 秒应看到 `UART heartbeat`
3. 手机打开 **nRF Connect**，扫描连接 **Nordic_UART_Service**
4. TX 特征（`6e400003`）打开 **Notify**
5. RX 特征（`6e400002`）点 **↑ Write**，Text 输入 `hello`，普通 Write
6. **电脑串口**应显示 `hello`
7. 电脑串口输入 `hi from pc` 后按 **Enter**
8. **手机 TX Notify** 应收到 `hi from pc`

RTT 对照：`Received ...: hello`、`UART RX from COM: ...`

## 数据流

```
手机 --BLE--> 52840 --P0.13 TX--> USB-TTL --> 电脑 COM
电脑 COM --> USB-TTL --P0.12 RX--> 52840 --BLE--> 手机
```
